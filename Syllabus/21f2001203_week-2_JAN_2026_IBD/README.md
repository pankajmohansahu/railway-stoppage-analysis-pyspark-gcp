# Week 2 - Graded Assignment 1: Longest Line Finder

## Assignment Overview

This project implements a Python program that analyzes a text file stored in Google Cloud Storage (GCS) to identify the longest line(s) based on character length. The program runs on Google Cloud Platform (GCP) using Cloud Shell and uses `gsutil` for all GCS operations.

## Problem Statement

- Download a text file from a GCS bucket
- Find the longest line(s) in the file based on character length
- If multiple lines share the maximum length, report all of them
- Print results in the terminal
- Create a formatted output report
- Upload output file to GCS bucket

## Files Included

### 1. `longest_line_finder.py`
Main Python script that performs the following operations:
- Downloads text file from Google Cloud Storage using `gsutil` via subprocess
- Analyzes the file to find longest line(s)
- Prints results to the terminal
- Creates a formatted output report file
- Uploads the output file back to GCS

### 2. `longest_lines_output.txt`
Output file generated by the script containing:
- Analysis report with timestamp
- Maximum line length found
- Count of lines with maximum length
- Complete list of all longest lines with line numbers

### 3. `sample_input.txt`
Input text file uploaded to GCS bucket for analysis.

### 4. `README.md` (this file)
Complete documentation explaining project structure, GCP setup, and how to run the script.

## Code Logic Explanation

The notebook implements the following workflow:

### 1. Setup and Configuration
- Installs `google-cloud-storage` library
- Imports required modules (storage, os, datetime)
- Configures bucket name and file paths

### 2. Download from GCS
- Initializes Google Cloud Storage client
- Connects to the specified bucket
- Downloads input file to local Jupyter environment

### 3. Find Longest Lines Algorithm
- Opens the downloaded file
- Iterates through each line
- Removes newline characters for accurate length calculation
- Tracks maximum length encountered
- Stores all lines matching the maximum length
- Records line numbers for reference

**Key Logic:**
```python
for line_num, line in enumerate(file, start=1):
    line_content = line.rstrip('\n\r')
    line_length = len(line_content)
    
    if line_length > max_length:
        # New longest line found
        max_length = line_length
        longest_lines = [line_content]
        line_numbers = [line_num]
    
    elif line_length == max_length and max_length > 0:
        # Another line with same maximum length
        longest_lines.append(line_content)
        line_numbers.append(line_num)
```

### 4. Display Results
- Formats results in a readable manner
- Shows maximum line length
- Lists all longest lines with their line numbers

### 5. Create Output File
- Generates formatted report with timestamp
- Includes analysis summary and complete results
- Saves to local file

### 6. Upload to GCS
- Uploads the output file back to GCS bucket
- Makes it available for download and submission
